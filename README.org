* Edward's X11 Dotfiles

Bare minimum dots to have a workflow that works for me.

To set up a machine (Ubuntu/Debian), clone to =~/x11-dotfiles= and run:

#+begin_src bash
git clone git@github.com:EdwardoSunny/x11-dotfiles.git ~/x11-dotfiles
~/x11-dotfiles/setup.sh
#+end_src

=setup.sh= is safe to re-run. It links =~/.config= to this repo (an existing =~/.config= is moved to =~/.config.bak-<date>= after asking), installs the apt packages the i3 config uses, installs the Symbols Nerd Font (bar/menu icons) into =~/.local/share/fonts=, and enables the xremap service if xremap is installed.

Other things:
- [[https://github.com/xremap/xremap][xremap]] (config is in the dotfiles)
  - Read and follow instructions under =Usage= to set up running =xremap= without sudo. Otherwise, systemd service will crash since it doesn't have the correct permissions to access inputs.
- [[https://github.com/pythops/bluetui][bluetui]] (install with cargo/rust; opened by clicking the bluetooth icon in the bar)

** i3 bar, launcher, audio and Wi-Fi
Everything lives in =.config/i3/scripts/= (Python stdlib only, no extra packages):
- =statusbar.py=: the bar (cpu, mem, bluetooth, network, mic, volume, clock). Blocks hide or fall back to text when a tool, device, or the icon font is missing; if the script can't start, i3 falls back to plain =i3status=.
- =launcher.py=: =$mod+space=; =rofi -show drun= if rofi is installed, else =dmenu_run=.
- =audio.py=: media keys and the audio device picker. Volume goes through =pactl=, so it works on PipeWire and PulseAudio, and is capped at 100% (higher is digital boost that just clips). Media keys use MPRIS over =gdbus=.
- =network.py=: Wi-Fi picker via =nmcli=. The menu opens instantly with NetworkManager's cached networks and a fresh scan (~10 s) fills in the rest live (with dmenu, which can't update, it waits for the scan). Hotkeys shown in the menu: =alt+h= hidden network, =alt+d= disconnect, =alt+w= Wi-Fi off, =alt+e= connection editor (the audio picker has =alt+m= for pavucontrol). Saved networks connect through their saved profile (even if the profile name differs from the SSID); new secured networks ask for the password in a masked prompt, and a failed attempt doesn't leave a profile with a wrong password behind. Enterprise (802.1X) networks open =nm-connection-editor=.
- =ui.py=: shared colors, icons, menus (=rofi= if installed, else =dmenu=), prompts, and notifications.

Look: monochrome. rofi uses =.config/rofi/themes/minimal.rasi= (translucent); =.config/picom/picom.conf= adds a blur behind rofi only (glx backend, everything else is picom's defaults).

Keys and clicks:
| Key / click                        | Action                                              |
|------------------------------------+-----------------------------------------------------|
| =$mod+space=                       | App launcher                                        |
| Volume up/down/mute, mic mute      | ±5% (capped at 100%) with an OSD notification       |
| Play/pause, next, previous, stop   | Control the active media player                     |
| =$mod+Shift+a= / click volume      | Pick output/input device (moves playing streams)    |
| =$mod+Shift+n= / click network     | Pick Wi-Fi network (+ hidden, disconnect, on/off)   |
| Scroll / middle / right on volume  | Change volume / mute / open pavucontrol             |
| Click / right click on mic         | Mute toggle / pavucontrol inputs                    |
| Click / right click on bluetooth   | bluetui (or blueman) / power on/off                 |
| Click cpu or mem                   | btop, htop, or top in a terminal                    |
| Hold =Alt+Enter=                   | Dictate with Handy (release to type the text)       |
| =$mod+Shift+t= / =$mod+Shift+Escape= | Handy hands-free start/stop / cancel              |

Short device names in the bar come from =ALIASES= in =audio.py=; unmatched devices use their full name.

** Handy (speech to text)
[[https://handy.computer][Handy]] is not an apt package: install the =.deb= from its [[https://github.com/cjpais/Handy/releases][releases]] (=sudo apt install ./Handy_<ver>_amd64.deb=). i3 starts it hidden and floats its =Recording= overlay (see the =Handy= block in =.config/i3/config=). Its settings are not in this repo (=~/.local/share/com.pais.handy/settings_store.json=); set these in the app:
- Transcribe shortcut =alt+enter=, push to talk on. Don't bind =Mod1+Return= in i3, or Handy can't grab it.
- Overlay style *Live* (shows the text while you speak), position *Top*: at the bottom the pill ends up under the i3 bar.
- Model *Parakeet Unified EN 0.6B* (streams, so the live text works), accelerator *Auto* (GPU through Vulkan, CPU fallback). The first few transcriptions after installing a model or driver are slow while the NVIDIA driver compiles its shaders; after that they take ~0.1 s.

** xremap things
The systemd service is already tracked in this repo under =systemd/user/=. Just run:
#+begin_src bash
systemctl --user daemon-reexec
systemctl --user daemon-reload
systemctl --user enable --now xremap.service
#+end_src

Check that its running:
#+begin_src bash
systemctl --user status xremap.service
#+end_src

** nvidia things (ubuntu)
For drivers, disable secure boot. Check via:
#+begin_src bash
mokutil --sb-state
#+end_src

Then first clean any broken/old deps: 
#+begin_src bash
sudo apt remove --purge '^nvidia-.*' 'libnvidia-.*' 'cuda-.*' -y
sudo apt autoremove -y
sudo apt clean
sudo apt update && sudo apt upgrade -y
#+end_src

Check devices:
#+begin_src bash
ubuntu-drivers devices
#+end_src

Install the recommended driver from list:
#+begin_src bash
sudo apt install nvidia-driver-580-open -y

# or auto install
sudo ubuntu-drivers autoinstall
#+end_src

For laptops with hybrid graphics, use on-demand:
#+begin_src bash
sudo prime-select on-demand
sudo reboot
#+end_src

Finally check with =nvidia-smi= and =xrandr= to make sure display and GPU works.
